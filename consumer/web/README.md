# @morphd/web

Offline, local-only React + Vite UI for morphd. It is served by the local Python engine;
there is no CDN and no runtime network access beyond loopback.

```sh
npm install
npm run dev       # use with `morphd serve` in another terminal (API only; dev UI origin differs)
npm run lint      # design-token/radius lint + tsc
npm test          # Vitest
npm run build     # emits ../../morphd/consumer/webui
```

The UI only calls the local API. Enforcement (budget, safety, state machines, key storage)
lives in the engine; the renderer never receives plaintext keys.

Design contract: only `#76B900`, `#FFFFFF`, `#000000`; no grey/gradients/transparency;
radii 4/6/8/10px (maximum 10); hard shadows; focus is always visible; status never relies on
color alone. `scripts/check-design.mjs` enforces the tokens at build time. Visual/focus/a11y
evidence is generated by `scripts/visual-check.mjs` with Playwright + Edge.
