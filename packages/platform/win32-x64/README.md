# @harness2-morphd/win32-x64

Platform package for harness2-morphd on Windows 10/11 x64. It contains the prebuilt engine at
`bin/morphd-engine.exe`, the bundled local Web UI, `SHA256SUMS`, `LICENSE` and `NOTICE`. It has
no install scripts and downloads nothing at runtime.

The current release binary is **unsigned**. Verify `SHA256SUMS` before running it; Authenticode
signing and SmartScreen reputation remain pending.
