# 服务条款摘要

> 完整法律文本应由发布方在正式发布前补齐并经受法律复核。本文件描述产品实际行为。

- **服务范围**：morphd 提供本地优先的 Agent harness 分析与改进建议。默认只建议，不自动改；
  自动应用需用户显式开启，并受安全扫描、预算、试用与撤销约束。
- **BYOK 计费**：模型调用由用户选择的服务商按其价格计费；morphd 不转售或代理模型调用，
  展示的价格为参考估算，以服务商账单为准。
- **无效果担保**：不保证模型输出、建议质量或任何特定业务结果；用户应在应用前查看 diff，
  并保留快照/撤销手段。
- **可接受使用**：不得使用本产品绕过组织的数据合规、权限或安全策略；不得提交恶意候选、
  凭据或违法内容。
- **用户责任**：用户对 workspace、会话数据与 API Key 拥有合法使用权，并负责服务商条款与
  所在组织的合规要求。
- **责任限制**：在适用法律允许范围内，发布方不对间接损失、模型服务商行为或用户误用负责。
- **开源许可**：代码以 Apache-2.0 发布；上游 Harness² 保留原版权/NOTICE。
- **终止/卸载**：用户可随时卸载集成、删除数据与 Key；卸载恢复宿主备份，不删除宿主自身文件。
- **变更**：重大变更会随发布说明提供；不静默改变默认信任等级或自动应用开关。
