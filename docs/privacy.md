# 隐私政策摘要

> 完整法律文本应由发布方在正式发布前补齐并经受法律复核。本文件描述产品实际行为。

## 收集与处理

- 默认只在本机处理会话摘要、候选、快照、预算与设置。
- 只有用户选择的模型服务商能看到**经过脱敏和最小化**的调用内容；发送前可预览。
- 不上传遥测（当前版本根本未实现外发遥测），不生成设备指纹，不上传会话原文、路径、代码或 Key。
- harness2-morphd 不使用用户数据训练模型；不同宿主/项目/设备间不共享经验。

## 存储

- 数据目录 `%USERPROFILE%\.morphd`（或 `MORPHD_HOME`），权限继承 Windows 用户配置目录 ACL。
- Key 优先 Windows Credential Manager；不可用时使用用户口令保护的 AES-GCM 本地保险库。
- 默认保留 30 天；可选 7/90/永久；可立即执行保留策略或删除。
- 日志滚动上限 100MB，脱敏，不含 Key 与会话原文。

## 第三方模型

- BYOK：请求直接发送到用户配置的端点，由用户与服务商结算；harness2-morphd 不代理、不转售。
- 用户需在首次启用服务商时确认其数据处理/保留/训练政策摘要。
- 未知价格不会按 0 计费；模型调用失败不会在后台无限重试。

## 用户权利

- 预览发送内容；导出不含 Key 的 JSON；删除单会话/单项目/全部数据；删除 Key；撤回同意并卸载。
- 关闭自动学习、隐身会话、项目级禁用、排除目录、仅本地模型均为随时可用。

## 安全边界

- 本地 API 仅 loopback，随机端口，引导令牌 + HttpOnly/Strict cookie + CSRF + CSP，禁止 CORS。
- 候选不得修改权限/沙箱/approval/hooks/settings/MCP，不得读取凭据或访问 workspace 外路径。
- Electron：contextIsolation、sandbox、nodeIntegration=false、preload 白名单、禁止远程页面、
  renderer 不接触 Key。

## 联系方式

由发布方在正式分发时提供隐私联系人、数据控制者信息与监管投诉渠道。
